### STEP 4: ASSIGNMENTREPOSITORYIMPL
File: Sources/GradeTracking/Data/FirestoreAssignmentRepositoryImpl.swift
Protocol: AssignmentRepositoryProtocol
Model: Assignment (with AssignmentType enum)

METHODS TO IMPLEMENT:
1. getAssignments(for classId) - filter by classId
2. getAssignment(by id) - simple get
3. createAssignment(_) - create
4. updateAssignment(_) - update (score updates here!)
5. deleteAssignment(id) - delete
6. getUpcomingAssignments(daysAhead) - query by dueDate
7. getAssignmentsDue(by date, for classId) - query by date + classId
8. observeAssignments(for classId) - listen
9. observeAssignmentChanges(for classId) - changes
10. stopObserving()

FIRESTORE COLLECTION: assignments/{id}
FIELDS:
- id: string
- classId: string (KEY)
- name: string
- dueDate: timestamp (KEY for date queries)
- description: string (optional)
- score: number (optional, updated when graded)
- maxScore: number
- weight: number (0-1, for GPA calculation)
- type: string (Homework|Quiz|Exam|Project|Other)
- createdAt: timestamp
- updatedAt: timestamp

SPECIAL CONSIDERATIONS:
- This is CRITICAL for grade calculations
- getUpcomingAssignments(daysAhead) needs:
  ```swift
  let todayStart = Calendar.current.startOfDay(for: Date())
  let futureDate = Calendar.current.date(byAdding: .day, value: daysAhead, to: todayStart)!
  query where dueDate >= today AND dueDate <= futureDate
  ```
- Grade tracking depends on accurate score/weight data
- Update is called frequently (when grades entered)

Protocol: GroupMessageRepositoryProtocol
Model: GroupMessage

METHODS TO IMPLEMENT:
1. getMessages(for groupId, limit) - query with limit
2. getMessage(by id) - simple get
3. sendMessage(_) - create (sendMessage = createMessage)
4. updateMessage(_) - update
5. deleteMessage(id) - delete
6. observeMessages(for groupId, limit) - listen with limit
7. observeNewMessages(for groupId) - only newly added messages (tricky!)
8. stopObserving()

FIRESTORE COLLECTION: groupMessages/{id}
FIELDS:
- id: string
- groupId: string (KEY)
- userId: string (sender)
- content: string
- createdAt: timestamp (for ordering)
- updatedAt: timestamp

SPECIAL CONSIDERATIONS:
- Messages need pagination/limits for performance
- observeMessages(limit) should:
  ```swift
  query.order(by: "createdAt", descending: true).limit(to: limit)
  ```
- observeNewMessages is tricky:
  - Only listen to messages created after NOW
  - Filter server-side in query:
  ```swift
  query.whereField("createdAt", isGreaterThan: Date())
  ```
- Remember to remove old listeners to prevent memory leaks
